Tools bundled for the first-run build (release model b). None of them contains game code or data.
- Zig 0.17.0 (tools/build/zig): MIT (LICENSE.zig.MIT.txt). The clang, lld, libc++, libunwind and compiler-rt inside it are LLVM
  projects, Apache-2.0 WITH LLVM-exception. mingw-w64 headers and CRT sources carry their own notices (public domain / ZPL / MIT-style)
  in tools/build/zig/lib/libc/mingw and lib/libc/include/any-windows-any.
- Python 3.13.15 embeddable package (tools/python): PSF License (LICENSE.Python.PSF.txt).
- capstone 5.0.9 (BSD-3-Clause) and lz4 4.4.5 (BSD-3-Clause) Python packages: licences in tools/python/Lib/site-packages/*.dist-info.
- nxrecomp lifter (tools/build/recomp): GPL-3.0-or-later (tools/build/recomp/LICENSE).
- spirv_harness (tools/spirv_harness): built on Ryujinx's shader translator (MIT, LICENSE.Ryujinx.MIT.txt) and the .NET runtime (MIT).
- Keyboard and mouse prompt icons (assets/kbm_icons): Kenney Input Prompts, CC0.
- AMD FidelityFX SDK v2.4.0 upscaler DLLs (upscalers/fsr3: amd_fidelityfx_loader_vk.dll, amd_fidelityfx_upscaler_vk.dll), unchanged and AMD-signed: MIT (LICENSE.FidelityFX-SDK-v2.4.0.txt).
- NVIDIA Streamline SDK v2.14.16 DLLs (upscalers/streamline: sl.interposer.dll, sl.common.dll, sl.dlss.dll), unchanged and NVIDIA-signed: MIT (LICENSE.Streamline.MIT.txt, NOTICE.Streamline-3rd-party.md).
- NVIDIA nvngx_dlss.dll (DLSS) is not in this package: its NVIDIA RTX SDKs LICENSE (LICENSE.NVIDIA-RTX-SDKs.txt) does not allow redistribution under a GPL-3.0 package. The launcher's Game files page downloads it from NVIDIA's DLSS repository when the player asks.
